# Fsaverage5

A surface template in fsaverage5 space for the glass brain plot

## Usage

``` r
fs5brain
```

## Format

### `fs5brain`

A list of two matrices: ()

- vertices:

  matrix with 3 rows (XYZ coordinates), 20484 columns (number of
  vertices)

- edges:

  matrix with 3 rows (triangle neighbours), 40960 columns (unique
  triangles)
